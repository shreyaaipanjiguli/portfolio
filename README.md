## Updating the portfolio

The deployed URL can stay the same while the content changes. After editing:

```bash
git add .
git commit -m "Update portfolio"
git push
```

If the repository is connected to GitHub Pages, Vercel, or Netlify, the deployed site will update after the new commit is built.

Keep project descriptions and learning claims accurate to current experience.
